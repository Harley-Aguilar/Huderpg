VISUAL EXCERPT · RECONSTRUCTED INTERFACE

Try the interface: edit a character name or attribute, adjust a resource and explore the tabs.

The challenge

Bring attributes, resources, skills and body modifications together without scattering character information.

The solution

A panel-based interface with category navigation and editable resources. Violet visual cues connect the tool to the game’s world.

What was built

Multiple characters, local saving, dice roll history, inventory, an implant map and JSON backup.

CURRENT VERSION SCOPE

Editable, local and system-specific.

The UTOPIA project stores data in the browser and supports JSON backups and manual transfers. Its current version does not include login, player synchronization or rules automation. The portfolio interface is a visual reconstruction, with a lightweight interactive demo below.
