THE IDEA

Complexity in the rules.
Clarity in the interface.

Identity, physical and mental attributes, resources, inventory and body modifications all need their place. The interface organizes these different layers into a single visual language, with dedicated spaces for the information players need.

DESIGN DECISIONS

01

Information first

Clear groups and a consistent hierarchy make the character easier to read and navigate.

02

A world of its own

Violet panels, technical typography and a body map connect the interface to the game’s cybernetic setting.

03

Tools for play

Character records, dice rolls and JSON backup support the everyday use of the sheet.

About this demonstration

The interactive preview uses sample data. You can edit fields, adjust resources and roll dice; changes reset on reload. The complete UTOPIA project includes local character storage and JSON backup. This version does not include player accounts, cloud synchronization or automated game rules.
